# 3주차 · 기획 & 착수

# 주제 확정

몽로그(MongLog) - 꿈을 기록하면 AI가 전통해몽 + 심리학적 해석을 섞어 해석해주고, 누적된 기록에서 반복되는 상징·감정·인물 패턴을 발견해주는 웹앱

주제 변경 이유 - 처음 기획했던 트렌드 대시보드가 숏츠,릴스와 같은 짧은 숏폼 영상을 가져와서 분석하려했지만 인스타API를 가져오는게 불가능하고 이 주제를 살린다면 다른 정보들(뉴스,주식,음악,,,) 을 가져오기엔 초기 기획한 의도와 많이 멀어진듯한 느낌을 받아서 주제변경하였음.

# 요구사항 정리

## 1. 프로젝트 개요

**이름**: 몽로그 (Mong-log)

**한 줄 소개**: 꿈을 기록하면 AI가 해석해주고, 누적된 기록에서 반복되는 상징·감정·인물 패턴을 찾아주는 앱

**기술적 차별화 포인트**: 단순 LLM 요약이 아니라, RAG 기반 해석 · 임베딩 클러스터링 기반 패턴 분석 · 통계 시각화 기반 월간 리포트로 실제 데이터 분석 파이프라인을 갖춘 프로젝트로 설계

**배경/맥락**: 땅울림 썸머코딩 LLM 스터디에서 진행하는 개인 프로젝트

**목적**:

- 꿈을 꾸준히 기록하고 AI 해석을 받는 과정을 통해, 사용자가 스스로도 인지하지 못했던 반복적인 감정·상징 패턴을 발견하고 자기 이해를 넓히도록 돕는다
- 단발성 재미가 아니라, 누적된 기록에서 드러나는 심리적 통찰("최근 자주 불안한 감정이 반복되네요" 같은 인사이트)을 핵심 가치로 제공한다

---

## 2. 핵심 기능 (MVP)

### 2.1 꿈 기록

- 텍스트로 꿈 내용 입력
- 날짜 자동 태깅
- (선택) 기상 직후 감정 상태 간단 체크
- 기억 선명도 체크 (예: 1~5점 척도로 얼마나 선명하게 기억나는지 입력)
- 등장인물 해시태그 입력 (선택 사항, 예: #엄마 #친구 처럼 태그 형태로 추가하거나 "기억 안남"으로 표시 가능)

### 2.2 AI 즉석 해석 — RAG 기반 (기록할 때마다 자동 실행)

- **해석 스타일**: 전통적 해몽(꿈해몽 사전) + 심리학적 해석(융/프로이트풍)을 섞은 톤
- 미리 구축한 꿈 상징 사전 DB(전통 해몽 자료 + 심리학적 상징 자료)를 검색(retrieval)한 뒤, 검색된 근거를 바탕으로 LLM이 해석을 생성 (RAG: Retrieval-Augmented Generation)
- LLM이 아는 척 지어내는 해석이 아니라, 실제 상징 사전 근거에 기반한 해석이라는 점이 기술적 차별점
- 핵심 요소(등장 인물/장소/사물) 추출
- 감정 톤 분석 (불안, 평온, 혼란 등)
- 꿈 분위기에 어울리는 AI 생성 이미지 함께 표시

### 2.3 패턴 발견 — 임베딩 클러스터링 기반 (버튼 클릭 시 수동 실행)

- 단순히 "이번 달 꿈들을 텍스트로 모아 요약"하는 방식이 아니라, 각 꿈 기록을 벡터(임베딩)로 변환해 저장
- 유사한 꿈끼리 벡터 유사도 기반으로 클러스터링
- 클러스터별로 대표 감정/상징을 추출해서 보여줌 (예: "불안-추락 계열" 클러스터, "그리움-재회 계열" 클러스터 등)
- 반복 등장하는 인물/장소/상징 랭킹
- 감정 변화 추이 그래프
- 클러스터 기반 주기적 인사이트 문구 (예: "최근 'OO 클러스터'에 해당하는 꿈이 잦아졌어요")

### 2.4 유명한 꿈해몽 탭

- 치아 빠지는 꿈, 하늘에서 떨어지는 꿈 등 대중적으로 유명한 꿈들의 해몽을 미리 정리해서 보여주는 탭
- 로그인 여부와 상관없이 누구나 열람 가능

### 2.5 온보딩 / 회원가입 유도 플로우

- 첫 방문 시 로그인 없이 꿈 기록 입력 가능
- 첫 기록에 한해 AI 해석 1회 무료 체험 제공
- 다음날 다시 이용하거나, 패턴 분석 버튼을 누르는 시점에 회원가입을 유도
- 회원가입 후에는 이메일/비밀번호 또는 소셜 로그인(구글, 카카오 등)으로 로그인
- 로그인한 사용자별로 본인의 꿈 기록만 조회/누적

### 2.6 감정 케어 - 수면 유도 영상 추천

- AI 해석 과정에서 감정 톤이 불안/악몽 등 부정적으로 분석된 경우
- 자기 전 침착해지도록 도와주는 수면 유도 유튜브 영상을 추천
- 감정이 안정적인 경우에는 노출되지 않음 (필요한 사용자에게만 자연스럽게 제안)

### 2.7 월간 리포트 — 통계 + 시각화

- 최근 한 달 기준 통계 요약
  - 총 꿈 기록 횟수
  - 악몽으로 분류된 횟수
  - 평균 기억 선명도
  - 자주 등장한 인물 태그 순위 ("기억 안남" 표시는 통계에서 별도 집계)
  - (패턴 발견 기능과 연계) 클러스터별 분포/감정 톤 분포
- 단순 텍스트 리포트가 아니라 시각화로 제공
  - 감정 변화 추이 그래프 (시간축 라인 차트)
  - 인물 네트워크 그래프 (등장인물 간 함께 등장한 관계를 노드-엣지로 표현)
  - 클러스터 분포 시각화 (예: 산점도/버블 차트)

# 개발 시작

- 외부 API (4개)
  | API | 용도 | 사용 위치 |
  |---|---|---|
  | Anthropic Claude API (claude-opus-5) | 꿈 해석(전통/심리학 해석, 요소·감정톤 추출), 클러스터 제목/인사이트 생성 | `lib/claude.ts` |
  | OpenAI Embeddings (text-embedding-3-small) | 꿈 텍스트·상징 사전 벡터화 (RAG 검색, 클러스터링용) | `lib/embeddings.ts` |
  | OpenAI Images (gpt-image-1) | 꿈 분위기 이미지 생성 (base64 반환) | `lib/image-gen.ts` |
  | YouTube Data API v3 (`/search` 엔드포인트) | 감정 톤이 불안/악몽일 때 수면 유도 영상 추천 | `lib/youtube.ts` |
- RAG 기반 해석(/api/interpret), 임베딩 클러스터링 패턴 분석(/api/analyze-patterns), 통계+시각화 월간 리포트(/api/monthly-report) 핵심 파이프라인 구현
- 주요 화면(꿈 기록 입력, 해석 결과, 기록 목록, 패턴 분석, 꿈 사전, 월간 리포트, 로그인) 구현
- 온보딩(익명 인증 → 회원가입 전환) 플로우 구현
