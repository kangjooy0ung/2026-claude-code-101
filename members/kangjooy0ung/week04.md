# 4주차 · WATCHMETA

## 🎯 이번 주 목표
WatchMeta MVP의 핵심 화면(전적 검색, 영웅 티어표)을 목업 데이터에서 실제 데이터 연동으로 전환하고, 백엔드 스캐폴딩과 배포 파이프라인을 구축합니다.

## 📚 진행 내용

### 백엔드 / 인프라
- OverFast API 프록시 백엔드 스캐폴딩 구현
- npm workspaces로 프론트/백엔드 모노레포 통합
- Render를 통한 백엔드 배포 설정, Vercel SPA rewrite 설정

### UI 전면 개편
- 메타/홈/검색 화면을 Overwatch Kinetic 다크 테마로 통일, 상단 네비바 도입
- 프로필 개요 화면을 탭 구조 → 카드 나열 구조로 개편
- 전적 페이지 PC 뷰를 12컬럼 레이아웃으로 재구성

### 영웅 티어표
- 전체 영웅 로스터·초상화·역할순 정렬 반영
- 공식 통계 기반 실제 픽률·승률 데이터 연동
- 픽률·승률 기반 메타 점수로 티어 재계산 로직 구현
- 등급별(랭크) 실제 데이터 반영 및 랭크 필터 연동
- *(진행 중)* 서버 필터(ServerFilter) 컴포넌트 추가, 영웅 픽률 데이터 대규모 확장 작업 진행 중

### 전적 검색 / 프로필
- 배틀태그 저장 기능 및 영웅별 통계 막대그래프 UI 추가
- 목업 데이터를 실제 API 연동으로 교체, 영웅별 상세 페이지 추가
- 오버워치 공식 패치노트 연동 화면 구현
- 전적검색/계정 메뉴 혼동 해소, 프로필 비공개 안내 문구에 오버워치 개인정보 설정 안내 추가

## 📝 공유
이번 주에 티어표는 픽률·승률 기반 메타 점수 로직까지 붙여 실제 랭크 필터와 연동했고, 전적 검색도 실제 API로 교체하며 영웅별 상세 페이지를 새로 붙였습니다. 다크 테마 전면 개편과 백엔드(OverFast 프록시) 배포까지 진행되어 데모 가능한 범위가 넓어졌습니다. 그리고 메타 티어표에 지역 서버 구분 기능도 추가하여 데이터를 더 유의미하게 볼 수 있도록 하였습니다
