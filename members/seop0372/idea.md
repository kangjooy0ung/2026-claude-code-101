# 💡 프로젝트 기획서 — SixUp (가안)

## 1. 한 줄 정의
뭘 시작해야 할지 모르는 사람을 위한, 관심사만 입력하면 6주 완성 취미 커리큘럼을 짜주는 웹서비스

## 2. 문제
"취미 갖고 싶은데 뭐부터 해야 할지 모르겠다"는 사람이 많다. 유튜브 등 정보는 많지만 흩어져 있고, 내 수준·시간에 맞게 정리가 안 돼서 결국 시작도 못 하고 흐지부지된다. 실제로 새해 결심처럼 새로운 걸 시작하려는 사람 중 **1년 뒤 실제로 목표를 달성한 비율은 12%에 불과했다** (Richard Wiseman, 2007, 3,000명 추적조사 — 시작 시점엔 52%가 성공을 확신했음에도). MZ세대의 **81%가 "취미 없인 못 산다"**고 답할 만큼 수요는 확실하지만(어피티, 2024, 815명 설문), 시작을 지속으로 이어가지 못하는 사람이 대다수다.

## 3. 해결책
관심 분야·주당 가능 시간·예산을 입력하면, AI가 주차별 목표·할 일·추천 자료(영상/글)를 담은 6주 커리큘럼을 자동으로 생성한다. 매주 체크인하며 진도를 추적한다.

## 4. 왜 지금
- AI를 활용하면 예전엔 학원·코치가 해주던 "전문가 수준의 맞춤 커리큘럼 설계"를 누구나 몇 초 만에 받을 수 있게 되었다.
- 왜 하필 6주인가: 새로운 행동이 습관으로 자리잡는 데 걸리는 시간은 평균 66일, 약 9.4주라는 연구 결과가 있다(Lally et al., 2010, UCL, 참가자 96명 12주 추적). 6주는 포기하지 않고 버틸 수 있는 현실적인 첫 구간으로 설계한 기간이다.

## 5. 사용자
새 취미를 시작하고 싶지만 계획 세우기가 막막한 20~30대. 특히 다양한 취미를 시도해보고 싶은데 매번 흐지부지되는 사람들.

## 6. 대안·경쟁
| 대안 | 강점 | 한계 |
|---|---|---|
| 유튜브 검색 | 정보는 풍부함 | 개인 맞춤이 없음, 정보 과잉으로 선택 피로 |
| 클래스101 / 탈잉 | 전문 강사 콘텐츠 | 커리큘럼이 고정, 비용 부담 |
| ChatGPT에 직접 물어보기 | 즉석에서 답 얻을 수 있음 | 진도 관리·추적 기능이 없어 대화가 끝나면 흐지부지됨 |

**차별점**: 진도 관리 + 리마인드 + 개인 상황(시간·예산) 맞춤화

## 7. 제품
1. 관심사·시간·예산 입력
2. 6주 커리큘럼 자동 생성
3. 주차별 체크리스트 및 진도 기록

**MVP 범위**: 1, 2번

## 8. 지속 방법
무료로 커리큘럼 1개 생성 가능. 여러 개 동시 진행하거나 심화 커리큘럼을 원하면 유료 전환. 완주율을 높이는 리마인드 알림도 프리미엄 기능으로 제공.
> 학습 프로젝트 범위상 실제 결제 연동은 하지 않고, 가격 정책 설계까지만 진행함.

## 9. 나(팀)
평소 다양한 취미를 시도해보고 싶은 니즈가 있어서, "뭘 시작해야 할지 몰라 결국 안 하게 되는" 이 문제를 직접 겪고 있음. 사용자 입장에서 진짜 필요한 서비스를 만들 수 있음.

## 10. 6주 계획
| 주차 | 내용 |
|---|---|
| 3주차 | 입력 폼 + 커리큘럼 생성 로직 구현 (완료) |
| 4주차 | 결과 페이지 디자인 + 저장 기능, SQLite 전환 |
| 5주차 | 체크리스트 / 진도 추적(%) 기능 붙이기, 실사용자 피드백 |
| 6주차 | 다듬기 + 배포 + 발표 준비 |
