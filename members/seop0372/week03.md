## 진행 상황
Claude(claude.ai)와 함께 백엔드(Express) + 프론트엔드(바닐라 JS) MVP를 설계·구현한 뒤,
Claude Code로 전환해 로컬 개발 환경을 세팅하고 Git 버전 관리를 시작했습니다.

이후 "ChatGPT에 직접 물어보는 것과 뭐가 다른가"라는 질문에 답하기 위해 세 가지
차별화 기능을 추가했습니다.

1. **맞춤 질문**: 목표만 입력하면 AI가 그 목표에 필요한 정보(예: 체지방 감량이면
   키/몸무게/체지방률, 악기면 보유 여부)를 스스로 판단해 먼저 물어보고, 답변을
   반영해 커리큘럼을 생성합니다.
2. **적응형 재조정**: 사용자가 어떤 주차를 완료 처리하면, 완료율에 따라 다음
   주차 계획을 더 도전적으로 또는 더 가볍게 조정할지 제안하고, 사용자가 선택한
   경우에만 실제로 반영합니다.
3. **자료 추천 + 메모**: "공부하기", "찾아보기" 같은 리서치형 할 일에는 관련
   자료를 연결하고, 모든 할 일에 자유롭게 메모(레시피 링크 등)를 남길 수 있습니다.

디자인도 흔한 SaaS 톤 대신, "새 취미를 시작하는 건 등산로 입구에 서는 것과
비슷하다"는 컨셉(Trailhead)으로 색상·타이포·진행률 표시를 다시 잡았습니다.

## 트러블슈팅
- AI 호출 시 "credit balance too low" 에러 → Anthropic 콘솔 결제 설정 안 한 게
  원인. 카드 등록 + 크레딧 충전으로 해결
- API 키를 실수로 채팅창에 노출 → 즉시 revoke 후 재발급, 이후 `.env` 파일에만
  입력하도록 습관 교정
- macOS 터미널 폴더 접근 권한 문제 → 시스템 설정에서 전체 디스크 접근 권한
  허용으로 해결
- 자료 추천 기능에서 AI가 실제 검색 대신 링크를 지어내서 404 발생 →
  web_search 결과의 실제 URL을 그대로 파싱하도록 수정 중
- GitHub 브랜치/PR 흐름이 처음이라 브랜치 경로를 잘못 지정해 파일이 엉뚱한
  위치에 생성되는 실수를 몇 차례 함 → 매번 History로 확인하며 재작업
