| 항목 | 내용 |
| --- | --- |
| **1. 한 줄 정의** | 취약계층 아동을 위한, AI 음성인식 기반 '주도적 기부·수혜' 플랫폼 |
| **2. 문제** | 학부모들은 복잡한 기부 절차(3박스 이상 수거, 직접 매장 방문) 때문에 기부 대신 폐기·지인 양도를 택하고, 아이는 기부 과정에서 소외되어 교육적 효과도 체감하지 못함 |
| **3. 해결책** | 아이가 음성으로 물품을 설명·감사편지를 쓰면 AI가 이를 정리해 수혜아동과 정서적으로 연결하고, ATM 거점 기반 간편 물류로 절차를 대폭 단순화 |
| **4. 왜 지금** | Whisper·GPT-4o 등 음성인식·멀티모달 AI 기술 성숙으로 아동의 비정형 발화도 구조화된 데이터로 변환 가능해졌고, 하나은행의 전국 ATM 인프라를 물류 거점으로 활용할 수 있는 환경이 갖춰짐 |
| **5. 사용자** | 기부 아동(영유아 자녀를 둔 부모)과 취약계층 수혜 아동 |
| **6. 대안·경쟁** | 기존 기부 플랫폼은 대량 수거·매장 방문 방식으로 진입장벽이 높음; 본 서비스는 1박스 단위 간편 수거 + 아동 주도 선택권 + AI 감성 편지로 차별화 |
| **7. 제품** | 	핵심 기능: ① AI 음성인식 기반 물품 게시글 작성 ② AI 감사편지(멀티모달) 매칭 시스템 ③ ATM 박스 수령→방문 수거 물류 |
| **8. 지속 방법** | 기부 횟수 연동 어린이 적금 우대금리(락인 효과) + ATM 내 전용 박스(패키지) 이용료 |
| **9. 나(팀)** | 프로젝트 기획 과정에 직접 참여하여 기능과 목적에 대한 이해도가 높음. 어린이집 보조교사 장기간 근무 경험으로 아동의 발화 수준이 어느정도 되는지 파악하고 있음 |
| **10. 6주 계획** | 3주: DB설계, API 명세서 작성, 사진,음성 저장할 클라우드 스토리지 세팅/ 4주: 프론트엔드 UI/UX 구현, AI 기능 연동, 백엔드 API 구현/ 5주: 배포, 테스트/ 6주: 배포 자동화 (CI/CD) 구축|
