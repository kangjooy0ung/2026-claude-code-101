# 프로젝트 기획서

| 항목              | 내용                                                                                                                                                                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. 한 줄 정의** | 여행을 계획하기 귀찮은 사람들을 위한, 다른 사람의 여행 플랜을 탐색하고 그대로 가져다 쓸 수 있는 여행 플랜 공유 플랫폼                                                                                                                                                                                              |
| **2. 문제**       | 새로운 여행지에 갈 때마다 일정, 동선, 숙소, 예산 등을 처음부터 조사해야 해서 시간과 노력이 많이 든다. 지금은 블로그·유튜브·커뮤니티 후기를 일일이 찾아보며 직접 플랜을 짜맞추는 식으로 견디고 있다.                                                                                                                |
| **3. 해결책**     | 검증된 플랜을 검색·필터링해서 그대로 가져오거나 손쉽게 커스터마이징할 수 있게 한다. 플랜 제작자(플래너)에게는 조회 기반 광고 수익을 배분해 콘텐츠 공급을 유도한다 — 정보 소비자(트래버)와 정보 생산자(플래너) 양쪽에 유인이 있는 구조.                                                                             |
| **4. 왜 지금**    | 여행 수요는 꾸준하지만, 계획 자체를 귀찮아하고 시간을 아끼려는 현대인의 성향은 점점 강해지고 있다. 크리에이터 이코노미(정보 생산자에게 보상하는 구조)가 보편화된 지금 시점에 잘 맞는 모델이다.                                                                                                                     |
| **5. 사용자**     | ① 트래버 — 플랜 짜기 귀찮은 여행 예정자. ② 플래너 — 자신의 여행 플랜을 공유해 광고 수익을 얻고 싶은 사람. 정확한 시장 규모는 아직 가설 단계.                                                                                                                                                                       |
| **6. 대안·경쟁**  | 패키지 여행 상품이 기존 대안이지만, 정해진 코스만 제공하고 개인화가 어렵다. 본 플랫폼은 누구나 어디든 자유롭게 플랜을 올리고 가져다 쓸 수 있으며, 여행사가 아닌 광고 수익 기반 구조라는 점이 차별점이다.                                                                                                           |
| **7. 제품**       | 핵심 기능 3가지: (1) 날짜·장소·인원·경비 필터링을 통한 플랜 탐색, (2) 주간/월간 인기 플랜 랭킹, (3) 플랜에 연동된 숙박·항공권 추천. 6주 MVP 범위는 플랜 탐색/필터링 + 플랜 등록·공유 기능까지.                                                                                                                     |
| **8. 지속 방법**  | 여행 관련 배너 광고, 호텔·항공권 제휴업체 등록(제휴 수수료) 기반 수익 모델. 플래너에게는 조회수 기반으로 수익을 일부 배분해 콘텐츠 생산을 유도.                                                                                                                                                                    |
| **9. 나(팀)**     | 본인은 여행 계획 짜는 게 싫어서 여행을 안 갈 정도로 이 문제를 직접 겪고 있어 사용자 니즈 파악에 유리하다. 또한 통신판매업 등록 및 웹사이트 제작 경험이 있어 개발뿐 아니라 사업 구조(사업자 등록, PG 입점 등)에도 실전 이해가 있다.                                                                                 |
| **10. 6주 계획**  | **3주차**: 핵심 데이터 구조 설계 + 플랜 탐색/필터링 MVP 개발. **4주차**: 플랜 등록·공유 기능 + 인기 플랜 차트 구현. **5주차**: 통신판매업 등록, PG사 입점 준비, 숙박·항공권 제휴 연동 조사. **6주차**: 마케팅 방향 설정 및 제휴업체 컨택, 베타 테스트 및 피드백 반영 (구체적인 마케팅 실행 방법은 아직 가설 단계). |
