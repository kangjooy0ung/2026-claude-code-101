1. 성능 개선
- 이미지 캐싱 적용해서 화면 이동할 때마다 사진 다시 안 불러오게 함
- 자주 조회하는 DB 쿼리에 인덱스 추가
- 트렌드/날씨 데이터 캐싱해서 매번 재조회 안 하게 함
- 로그인 직후 탭 4개가 한꺼번에 로딩되던 거 → 방문한 탭만 로딩되게 수정
- 설정 탭에서 체형정보, 개인정보 수정 화살표 추가

2. 신규 기능 + UI 개선
- 옷장 아이템에 #데이트, #여름 같은 해시태그 달 수 있게 추가 → AI 추천할 때 이 태그 참고해서 추천해줌
- 홈 화면 추천 결과에서 상/하의 따로 보여주던 거 → 한 카드에 다 같이 보이게 통합
- AI 검색창 UI 정리(버튼-입력창 간격 등) + 예시 질문 칩 추가

3. 네이버쇼핑 구매 연동
- 네이버쇼핑 API가 이번 주에 공개 종료돼서 '+1 아이템' 구매 링크 기능이 안 뜨는 상태였음
- 지금은 11번가나 다른 API 중에 구매자한테 상품 링크 제공해주는 게 있는지 알아보는 중
- 대안 찾을 때까지는 일단 상품명/추천 이유만 텍스트로 보여주는 상태로 유지
