### 2. 직접 써본 프로젝트 및 작업
- **사용한 프로젝트:** spring-guides/gs-rest-service (스프링 공식 가이드 프로젝트)
- **시킨 작업:**
    - Claude Code에게 `GreetingController.java` 파일을 분석하게 한 뒤, `/hello` 경로로 GET 요청이 들어오면 "안녕하세요!"를 반환하는 새로운 API 엔드포인트(`@GetMapping("/hello")`) 로직을 추가하도록 지시했습니다.
    - 이후 코드 수정 사항에 대해 프로젝트 맥락에 맞는 커밋 메시지를 스스로 작성하고 `git commit`을 수행하는 과정까지 에이전트에게 위임하여 성공적으로 자동화된 워크플로우를 테스트했습니다.
### 3. 공유거리
- **신기했던 것:**
  - git 커밋을 위임했을 때 코드 변경점을 파악해 커밋 메시지를 알아서 작성해 주는 점이 신기했습니다.
  - 예전에는 초기 세팅을 일일이 수동으로 추가해야 했는데, `/init` 명령어 한 번으로 프로젝트를 분석해 가이드 토대를 자동으로 만들어주는 기능이 무척 편리하게 느껴졌습니다.
  - 코드를 일부러 망가뜨려 오류를 낸 뒤 고쳐보라고 지시했을 때, 에이전트가 스스로 터미널 로그를 읽고 원인을 찾아 완벽하게 고쳐놓는 과정이 가장 놀라웠습니다.
- **이상했던 것:**
  - 간단한 코드 추가인데도 프로젝트 구조를 파악하느라 생각보다 고민하는 시간이 길어서 조금 답답하게 느껴졌습니다.
