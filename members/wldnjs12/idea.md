# 💡 프로젝트 기획서 — <TrendFit>

| 항목 | 내용 |
| --- | --- |
| **1. 한 줄 정의** | 유행에 관심 많은 사람을 위한 "요즘 유행을 내 옷으로 어떻게 입지" 자동 코디 추천 서비스 |
| **2. 문제** | SNS로 유행은 매일 보는데 내 옷으로 재현을 못 함 → 또 사거나 포기. 기존 옷장 앱은 최신 유행과 단절됨 |
| **3. 해결책** | 최신 트렌드 자동 수집 → 내 옷장·취향과 결합 → 유행을 내 옷으로 소화한 코디 추천 + 부족한 아이템 제안 |
| **4. 왜 지금** | AI로 트렌드 정제·옷 자동 태깅 가능 |
| **5. 사용자** | 	유행 민감하지만 매번 사긴 부담인 20~30대(1차: 나·지인) |
| **6. 대안·경쟁** | 에이클로젯(내 옷장 중심, 실시간 트렌드 반영 X), SNS(내 옷과 연결 X). 차별점: 트렌드 → 내 옷장 번역 |
| **7. 제품** | 	①트렌드 수집·정제 ②옷장 등록(자동 태깅 + 크롭 처리 + 점진적 등록) ③번역 추천 엔진(+1 아이템 구매 시 자동 등록) · MVP = ②③ (①은 공개 소스로 최소 구현) · 스트레치: 완전 배경제거(누끼), SNS 연동, 캘린더 |
| **8. 지속 방법** | 무료로 시작해 사용자 확보 → 추천 아이템 쇼핑몰 제휴 수수료 + 유료 프리미엄으로 수익화. AI 비용은 사진 1회만 분석·트렌드는 몰아서 갱신해 절약 |
| **9. 나(팀)** | 	학교 수업에서 옷장 매칭 프로토타입 제작 경험이 있고 스스로가 타깃 유저이다  |
| **10. 6주 계획** | 3주: 셋업·트렌드 정제 파이프라인 / 4주: 옷장 등록·태깅 / 5주: 번역 추천 엔진·화면 / 6주: 다듬기·배포·발표 |
