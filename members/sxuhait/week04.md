## 이번 주 진행
- 이메일 회원가입 + 역할 구분(멘토/봉사자/관리자), 관리자는 별도 지정
- 봉사자 계정 만료(마지막 활동 후 30일) — 로그인/페이지/DB 3중 차단, 실제 테스트 완료
- 담당제 폐지 → 공용 명단(모든 멘토가 학생 전체 공유)
- 관리자 전용 센터 수업 관리
- 상단 네비 + 새싹/파스텔 테마로 디자인 통일
- 센터 행사 사진 업로드(Supabase Storage), 알림 기능
- 멘토 출근 스케줄, 봉사자 오늘 참석 체크, 행사 시간대별 일정
- 실사용 준비: 멘토가 직접 학생 추가/검색, 추가 후 바로 일지 작성
- 앱 내 피드백 기능(별점+의견, 관리자 조회)

## 겪은 문제 / 해결

- 데이터 접근 권한(RLS) 재설계로 역할별 격리 및 봉사자 만료 3중 차단
