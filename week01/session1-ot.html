01Claude Code의 본질 — "자동완성이 아니라 에이전트"

💬 챗봇 (ChatGPT)

코드를 "알려주는" 도구

질문 → 답변 복사 → 내가 붙여넣고 실행. 내 코드베이스를 모른다.

✨ 자동완성 (Copilot)

코드를 "이어주는" 도구

내가 타이핑하는 동안 다음 줄 제안. 주도권은 여전히 내 손가락.

🤖 에이전트 (Claude Code)

일을 "맡기는" 도구

스스로 코드를 탐색하고 → 계획하고 → 수정하고 → 실행·테스트로 검증한다.

핵심 차이: 코드 조각을 받는 게 아니라, "이 버그 고쳐줘"라는 목표 자체를 위임할 수 있다

01Claude Code 해부학 — 구조는 놀랍도록 단순하다 🔬

// Claude Code의 본질 = 모델 + 얇은 하네스
while (!done) {
  context = gather(파일, git, CLAUDE.md)
  action  = model.think(목표, context)
  result  = tools.run(action) // Read·Edit·Bash·Search
  done    = verify(result)    // 테스트·빌드로 검증
}

🧠 지능은 전부 모델에

복잡한 파이프라인 없음. 탐색·계획·수정·검증을 결정하는 건 루프가 아니라 모델 자신

🔧 하네스는 손과 발만

파일 읽기/쓰기, 터미널, 검색 — 도구와 권한 시스템만 제공하는 의도적으로 얇은 껍데기

💬 "Claude Code는 의도적으로 저수준이고 무의견(unopinionated)합니다 — 날것에 가까운 모델 접근을 제공합니다" — Boris Cherny, Claude Code 창시자 (Anthropic 엔지니어링 블로그)

01드라마틱한 일이 벌어지는 조건 ⚡

같은 도구인데 누구는 10배 생산성, 누구는 "별로던데요?" — 마법이 아니라 조건의 문제입니다

1️⃣ 명확한 목표

"로그인 버그 고쳐줘"보다 "이 재현 절차로 발생하는 401 오류를 고쳐줘" — 목표가 구체적일수록 결과가 극적

2️⃣ 검증 가능한 피드백 루프

테스트·컴파일러·린터가 있으면 AI는 스스로 틀림을 발견하고 고칩니다. Anthropic 연구진이 말하는 발전의 핵심 조건 — "검증 가능한 보상"

3️⃣ 풍부한 맥락

CLAUDE.md, 좋은 README, 정돈된 코드베이스 — 신입 개발자에게 주듯 맥락을 주면 그만큼 일합니다

4️⃣ 위임의 크기와 반복

한 줄씩 시키면 자동완성, 목표째 맡기고 반복시키면 에이전트 — 위임 단위가 클수록 드라마가 커집니다

💬 "3~6개월 안에 AI가 코드의 90%를 쓰게 될 것" — Dario Amodei (2025.3) · 이 조건들을 갖추는 사람부터 그 90%의 수혜자가 됩니다

04기본 세팅 ② — VS Code 연동

  • 확장 자동 설치VS Code 내장 터미널(⌃`)에서 claude 실행 → Claude Code 확장이 자동 설치됨 (마켓플레이스에서 "Claude Code" 수동 설치도 가능)
  • 단축키로 열기Mac Cmd+Esc / Windows Ctrl+Esc — 어디서든 Claude Code 패널 토글
  • 컨텍스트 공유에디터에서 코드 드래그하면 선택 영역이 자동으로 대화에 포함 · Cmd+Option+K로 현재 파일 참조(@파일#라인) 삽입
  • Diff를 에디터에서Claude가 제안한 수정이 VS Code diff 뷰어로 표시 → 검토 후 수락/거절

04기본 세팅 ⑥ — 막혔을 때 (트러블슈팅)

  • command not found: claudenpm 글로벌 경로가 PATH에 없는 경우 — npm config get prefix 확인 후 PATH에 추가, 또는 터미널 재시작
  • npm 권한 오류 (EACCES)sudo 대신 npm 글로벌 디렉토리를 홈으로 변경하는 것을 권장 — 같이 해결해드립니다
  • Windows에서 잘 안 될 때WSL(Ubuntu) 설치 후 WSL 안에서 Node + Claude Code 설치 권장
  • 로그인 루프 / 크레딧 오류구독 계정과 브라우저 로그인 계정이 다른 경우가 대부분 — /login 으로 계정 재선택

🛟 그래도 안 되면 → 화면 공유 + 멘토 2명이 달라붙습니다
